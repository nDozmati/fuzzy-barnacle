# fuzzy-barnacle
Repo for CS4100 projects for Nicolas Dozmati and Matt Carpenter

## Project 1: CMOS Plagiarism Detection Simulator
A lexical analyzer and parser for winnowing algorithm for plagiarism detection using Flex.

## Project 2: TreeBuilder Language Interpreter
An interpreter for the TreeBuilder programming language, supporting variables, arithmetic, and control structures.

## Project 3: TreeBuilder Language Compiler
A compiler for the TreeBuilder language that parses tree construction code, builds a tree in memory, and outputs the tree structure in a specified format.

### Usage
- Build: `make`
- Run: `make run` (uses Examples/ex1.tree)
- Clean: `make clean`

### Output
- Tree structure printed to stdout
- Debug build details in debug.txt
